## 📌 Objetivo do Projeto
Este projeto foi desenvolvido como parte de um programa de iniciação em tecnologia. O sistema visa conscientizar e ajudar usuários a estimarem o consumo mensal de energia elétrica (em kWh) e o custo financeiro aproximado de seus aparelhos eletrônicos a partir de dados simples de uso diário.

---

## 🧮 Fórmula Utilizada

O cálculo do consumo mensal segue a fórmula padrão do setor elétrico:

$$\text{Consumo Mensal (kWh)} = \frac{\text{Potência (W)} \times \text{Uso Diário (horas)} \times 30}{1000}$$

> **Custo Estimado:** Multiplica-se o consumo mensal resultante por uma tarifa média estipulada em **R$ 0,75/kWh**.
